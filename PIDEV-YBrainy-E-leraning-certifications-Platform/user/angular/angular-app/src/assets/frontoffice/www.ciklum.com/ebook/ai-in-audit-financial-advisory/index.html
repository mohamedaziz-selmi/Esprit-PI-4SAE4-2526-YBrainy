    About This Course

    Discover how leading audit and financial advisory firms are using AI to deliver faster, sharper, and more trustworthy financial insights in a high-risk, high-regulation world.

    This comprehensive course takes you from the fundamentals of AI in auditing through advanced techniques in fraud detection, compliance automation, and building trustworthy AI systems. You'll gain hands-on experience with real-world tools and frameworks used by top financial institutions.

    By the end of this course, you'll be equipped to:

    • Implement AI-powered audit workflows that analyze 100% of transactions in real time
    • Deploy anomaly detection and process mining tools for financial risk assessment
    • Build compliance review systems using Large Language Models
    • Design explainable AI systems that meet IFRS, SOX, and emerging AI regulatory requirements

    Requirements

    • Basic understanding of financial auditing concepts
    • Familiarity with data analytics tools (Excel, SQL basics)
    • No prior AI/ML experience required – we start from the fundamentals
